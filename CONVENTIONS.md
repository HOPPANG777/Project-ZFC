# 코딩 컨벤션 (Coding Conventions)

## 주석 (Comments)

### 0. 기본 원칙

| 상황 | 사용 | 예시 |
| --- | --- | --- |
| 한 문장 ~ 두 문장 | `//` | `// 레이어들을 초기화한다.` |
| 세 문장 이상 / 긴 설명 | `/* ... */` | 여러 줄에 걸친 설명 블록 |

- 주석은 "코드가 무엇을 하는지"가 아니라 **왜 그렇게 했는지(의도, 제약, 트레이드오프)** 를 남긴다.
- 코드만 봐도 자명한 내용(`// i를 1 증가` 같은)은 달지 않는다.

---

### 1. 구분선 종류와 위계

구분선은 **폭과 문자로 위계(레벨)를 나눈다.** 위로 갈수록 큰 단위다.

| 레벨 | 스타일 | 쓰임 |
| --- | --- | --- |
| 최상위 | `//====` (풀 폭) | 파일 헤더, 함수/클래스 정의 헤더, Synopsis |
| 대구획 | `//****` (풀 폭) | `.cpp` 내부의 큰 논리 구획 배너 |
| 섹션 | `//====` (짧은 폭) | include / 전방선언 등 영역 라벨 |
| 소구획 | `///////` | 클래스 내부의 멤버 그룹 나눔 |

각 레벨의 생김새 예시:

```cpp
//=============================================================================
// [최상위] 파일 헤더 / 함수·클래스 정의 헤더 / Synopsis 에 사용
//=============================================================================

//******************************************************************************
//
// [대구획] .cpp 내부 큰 논리 구획 배너
//
//******************************************************************************

//========================================
// [섹션] include / 전방선언 영역 라벨
//========================================

///////////////////////////////////////////////////////////////////////
// [소구획] 클래스 내부 멤버 그룹
///////////////////////////////////////////////////////////////////////
```

한 파일 안에서 위계가 어떻게 겹쳐 쓰이는지:

```cpp
//=============================================================================
// [최상위] 파일 헤더
//=============================================================================

//========================================
// [섹션] System Includes
//========================================
#include <mylib/mytypes.h>

//******************************************************************************
//
// [대구획] Public Member Functions
//
//******************************************************************************

//=============================================================================
// [최상위] MyClass::MyFunc
//=============================================================================
void MyClass::MyFunc()
{
}
```

### 2. 파일 헤더 블록 (파일 최상단)

**쓰임:** 파일의 신원(파일/컴포넌트 이름, 설명, 변경 이력)을 파일 맨 위에 한 번 기록한다. 파일을 열자마자 "무엇을 하는 파일인지, 누가 언제 왜 만졌는지"를 알 수 있게 한다.

- `File:` 은 개별 파일 단위일 때, `Component:` 는 하나의 시스템/모듈을 대표하는 파일일 때 사용한다.
- `History:` 에는 `날짜 + 변경 내용 -- 작성자` 형식으로 이력을 누적한다.
- 저작권 표기는 사용하지 않는다(필요해지면 그때 첫 줄에 추가한다).

```cpp
//=============================================================================
// File:        myclass.cpp
//
// Description: Implement MyClass
//
// History:     12/07/2026 + Created -- MyName
//
//=============================================================================
```

컴포넌트 단위일 때:

```cpp
//=============================================================================
// Component:   MyManager
//
// Description: MyManager 는 외부 시스템이 MyModule 과 상호작용하기 위해
//              필요한 모든 인터페이스를 제공한다.               [12/07/2026]
//
// History:     + 초기 인터페이스 구현        -- MyName [12/07/2026]
//
//=============================================================================
```

---

### 3. 섹션 라벨 (짧은 `//====`)

**쓰임:** 파일 내부의 영역(include 그룹, 전방선언 등)을 나눠 시각적으로 구분한다. include 를 성격별로 묶어서 어디서 온 의존성인지 빠르게 파악하게 한다.

대표 라벨: `System Includes`, `Project Includes`, `Nested Includes`, `Forward References`

```cpp
//========================================
// System Includes
//========================================
// Foundation Tech
#include <mylib/mydebug.h>
#include <mylib/mymath.h>

//========================================
// Project Includes
//========================================
#include <myproject/myclass.h>
#include <myproject/myhelper.h>
```

- `// Foundation Tech` 처럼 섹션 안에서 다시 성격이 갈리면 `//` 한 줄짜리 소분류 주석으로 묶는다.

---

### 4. 전방선언 / 조건부 include 표시

**쓰임:** 전방선언(fwd dec) 묶음임을 명시하고, 특정 선언이 왜 여기 있는지(비정상적/맥락 필요) 짧게 남긴다.

```cpp
//fwd dec's
class MyClass;
class MyHelper;
class MyScene;

//MyName: 구름 렌더링을 위해 추가함.
class MyController;
```

- `//fwd dec's` : 전방선언 블록 표시.
- 개별 선언 위 한 줄 주석 : **왜** 이 선언이 필요한지(누가/어떤 이유로 추가했는지) 맥락을 남긴다.

---

### 5. TODO 블록

**쓰임:** 나중에 손봐야 할 구조적 개선점을 눈에 띄게 박아둔다. 짧으면 `// TODO:` 한 줄, 설명이 길면 섹션 블록으로.

```cpp
//========================================
// TODOs: 아래 데이터셋을 다른 파일로
//        재캡슐화할 것:
//========================================
```

---

### 6. Synopsis 블록 (클래스/타입 설명)

**쓰임:** 클래스 정의 바로 위에 그 타입이 "무엇이고 어떤 책임을 지는지" 요약한다. 파일 헤더의 Description 이 파일 수준이라면, Synopsis 는 타입 수준의 설명이다.

```cpp
//=============================================================================
//
// Synopsis:   MyManager;
//                - 모든 비(非) 렌더 시스템의 진입점
//                - 지원 기능
//                   - ContextSwitch 인터페이스        -- MyName [12/07/2026]
//                   - DXI 인터페이스
//=============================================================================
class MyManager
{
    // ...
};
```

### 7. 함수 정의 헤더 블록

**쓰임:** `.cpp` 에서 각 함수 구현 위에 붙여, 함수의 설명/매개변수/반환값을 정형화된 형태로 문서화한다. 함수 경계를 시각적으로도 확실히 나눈다.

- 항목: `Description`, `Parameters`, `Return`
- 없으면 `None.` / `N/A.` / `void` 로 명시(빈칸으로 두지 않는다).

```cpp
//=============================================================================
// MyClass::MyFunc
//=============================================================================
// Description: 대상 위치를 설정한다.
//
// Parameters:  ( const MyVector& position )
//
// Return:      void
//
//=============================================================================
void MyClass::MyFunc( const MyVector& position )
{
    mTransform.SetTranslation( position );
}
```

생성자/소멸자처럼 매개변수·반환이 없을 때:

```cpp
//=============================================================================
// MyClass::MyClass
//=============================================================================
// Description: Constructor.
//
// Parameters:  None.
//
// Return:      N/A.
//
//=============================================================================
MyClass::MyClass()
{
}
```

### 8. 대구획 배너 (`//****`)

**쓰임:** `.cpp` 파일 안을 큰 논리 단위로 나누는 배너. 함수 헤더(레벨: 개별 함수)보다 상위 개념으로, 여러 함수를 묶는 "구역"을 표시한다.

대표 배너: `Global Data, Local Data, Local Classes`, `Public Member Functions`, `Private Member Functions`

```cpp
//******************************************************************************
//
// Public Member Functions
//
//******************************************************************************

// ... 여러 public 함수 구현들 ...

//******************************************************************************
//
// Private Member Functions
//
//******************************************************************************
```

---

### 9. 클래스 내부 소구획 divider (`///////`)

**쓰임:** 헤더의 클래스 선언 안에서 멤버들을 성격별 그룹으로 나눈다. 인터페이스별(콜백 구현 등)로 묶어 어떤 계약을 구현하는 멤버인지 보이게 한다.

대표: `Accessors`, `MyCallback's`, `EventListener` 등

```cpp
   ///////////////////////////////////////////////////////////////////////
   // Accessors
   ///////////////////////////////////////////////////////////////////////
   MyScene* pScene();
   MyLayer* pLayer();

   ///////////////////////////////////////////////////////////////////////
   // MyCallback's
   ///////////////////////////////////////////////////////////////////////
   virtual void OnLoaded( MyEntity* pEntity, int userData );
```

- 그룹 안에서 더 잘게 나눌 땐 `// Context Interface`, `// Layer Interface`, `// Static Methods (...)` 처럼 `//` 한 줄 라벨을 쓴다.

---

### 10. 코드 바로 위 짧은 설명 주석

**쓰임:** 바로 아래 한두 줄 코드의 의도를 설명한다. 특히 "왜 이렇게 막아뒀는지" 같은 방어적 코드의 이유를 남긴다.

```cpp
   // 불필요한 복사 생성을 막는다.
   MyClass( const MyClass& other );
   MyClass& operator=( const MyClass& other );
```

```cpp
   // 레이어들을 초기화한다.
   void InitLayers();
```

---

### 11. 트레일링(같은 줄) 주석

**쓰임:** 선언 오른쪽에 붙여, 그 변수의 실제 의미/실제 타입을 간단히 보충한다.

```cpp
   int mLayer;   // MyEnums::LayerEnum
   int mLevel;   // MyEnums::LevelEnum
   int mMission; // MyEnums::MissionEnum
```

- 멤버 변수의 역할 설명은 선언 위 `//` 한 줄로 두는 것도 허용한다.

```cpp
        // 현재 인덱스. 매 tick 마다 증가.
        int mCurrentIndex;
        // 배열 값들의 합.
        unsigned int mSum;
```

### 12. HACK / 버그 추적 메모

**쓰임:** 임시방편(hack)이거나 정상적이지 않은 코드에 대해, 그 사실과 **추적 경로(버그 번호 등)** 를 남긴다. 나중에 왜 이런 코드가 있는지 추적 가능하게 한다.

```cpp
// 캐시 보관용 임시 이름. 정상 구조 아님.
// 버그 트래커 #1259 로 추적 중.
//
const char MYCACHE[] = "MyResourceCache";
```

---

### 13. 짧은 노트 박스

**쓰임:** 함수/유틸리티 위에 가볍게 붙이는 설명. 정형 헤더(7번)까지는 필요 없지만 한 줄 의도는 남기고 싶을 때 위아래 `//` 로 감싼다.

```cpp
//
// 이 싱글턴에 접근하기 위한 간단한 헬퍼.
//
inline MyManager* GetMyManager()
{
   return( MyManager::GetInstance() );
}
```
