# Project-ZFC

이 프로젝트는 내 실력 향상을 위해서 시작합니다.

처음에는 CMD창 게임을 만들고.
그 게임을 계속 발전시킵니다.
이후에는 저수준 API를 사용해서 엔진을 만듭니다.
그리고 처음 만든 게임을 그 엔진으로 이식합니다.

최종 목표는 스팀에 제출이 가능할 정도의 퀄리티를 가진 게임을 만드는 것이다.

## 프로젝트 이름

프로젝트 이름은 `Project-ZFC`로 한다.

처음에는 `Project-` 형식의 이름을 원했다.
그중에서 `Project-ZFC`가 괜찮다고 생각했다.

`ZFC`는 `Zero Forge Core`로 생각한다.

- `Zero`: 처음부터 시작한다는 의미
- `Forge`: 직접 만들고 단련한다는 의미
- `Core`: 엔진의 핵심이라는 의미

## 이름 표기

프로젝트 이름에는 언더바 `_`보다 하이픈 `-`을 사용한다.

그래서 최종 표기는 아래처럼 한다.

```text
Project-ZFC
```

폴더명이나 저장소명도 하이픈을 기준으로 잡는다.

```text
project-zfc
zfc-engine
zfc-game
```

언더바 `_`는 코드 안에서 식별자나 매크로를 쓸 때 사용하는 쪽이 더 맞다고 생각한다.

```cpp
zfc_core
ZFC_CORE
```

## 진행 방향

처음부터 크게 만들려고 하지 않는다.

먼저 CMD창 게임을 만든다.
그 다음 게임을 발전시킨다.
이후 저수준 API를 사용해서 엔진을 만든다.
마지막으로 게임을 그 엔진으로 이식한다.

이 프로젝트는 게임을 완성하는 것뿐만 아니라,
내가 게임과 엔진을 직접 만들면서 실력을 올리는 것도 목표다.
