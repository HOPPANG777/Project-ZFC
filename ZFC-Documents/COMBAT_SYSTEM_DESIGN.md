# Project-ZFC 전투 시스템 기획서

> 버전: v2.0  
> 범위: 전투 시스템  
> 장르: 타일 기반 턴제 로그라이크  
> 문서 목적: 기획, 구현, 테스트 기준 통일

## 1. 게임 방향

### 1.1 장르

- 2D 타일 기반 턴제 로그라이크
- 방 단위 전투
- 런 기반 성장
- 덱빌딩 성장 요소
- 스탯, 패시브, 유물 확장

### 1.2 핵심 방향

- 모험 요소는 제외한다.
- 전투와 보상 선택의 반복을 메인 콘텐츠로 사용한다.
- 공격 예고를 확인하고 회피, 방어, 끊기 중 하나를 선택한다.
- 자세에 따라 같은 행동의 효과와 보상이 달라진다.
- Tempo로 공격적인 대응을 추가 행동으로 연결한다.
- 턴 부채로 미래 행동을 앞당기고 이후에 대가를 지불한다.
- 플레이어와 적 모두 HP, 체간, Tempo를 사용한다.
- 플레이어는 자세를 전환하고 적은 종류별 고정 자세를 사용한다.

### 1.3 게임 루프

```text
전투 시작
-> 전투 해결
-> 보상 선택
-> 다음 전투
-> 보스 전투
-> 런 종료
```

- 모든 전투는 타일맵에서 턴제로 진행한다.
- 전투 종료 후 카드, 스탯, 패시브, 자세 강화 중 하나를 선택한다.
- 전투를 반복하며 빌드를 완성한다.
- 전투에서 패배하면 현재 런을 종료한다.

## 2. 용어

| 용어 | 정의 |
| --- | --- |
| HP | 생명력. 0이 되면 사망한다. 플레이어가 사망하면 전투에서 패배한다. |
| 체간(Poise) | 피격과 방어로 증가하는 경직 게이지. 최대치에 도달하면 다음 행동 1회를 잃는다. |
| Tempo | 전투 중 조건을 달성해 얻는 자원. 플레이어는 추가 행동 등에 사용하고 적은 강공격 준비에 사용한다. |
| 턴 부채(Turn Debt) | 미래 행동을 앞당겨 추가 행동을 사용한 횟수. 다음 턴부터 행동 손실 또는 Tempo로 상환한다. |
| 자세(Stance) | 유닛의 전투 방식. 공격, 방어, 기동 자세로 구분한다. |
| 공격 예고(Telegraph) | 다음 적 행동에서 발동할 공격의 방향과 범위를 미리 표시하는 기능이다. |
| 위험 타일 | 예고 공격이 발동할 때 공격 판정이 발생하는 타일이다. |
| 경직(Stagger) | 체간 최대치 도달로 인해 다음 행동 1회를 잃는 상태다. |
| 끊기 | 예고 중인 적의 체간을 파괴해 준비 중인 공격을 취소하는 대응이다. |

## 3. 전투 맵

### 3.1 좌표계

- 2D 사각 격자를 사용한다.
- 좌상단을 `(0, 0)`으로 사용한다.
- 기본 이동 방향은 상하좌우 4방향이다.
- 기본 이동은 인접한 타일로 1칸 이동한다.

### 3.2 점유 규칙

- 한 타일에는 유닛 1개만 존재할 수 있다.
- 벽과 장애물 타일은 이동할 수 없다.
- 유닛이 점유한 타일로 이동할 수 없다.
- 위험 타일은 점유 여부와 별개로 표시되는 전투 정보다.

### 3.3 타일 타입

```cpp
enum class TileType
{
    Empty,
    Wall,
    Danger
};
```

콘솔 버전의 기본 표기는 다음과 같다.

| 문자 | 의미 |
| --- | --- |
| `@` | 플레이어 |
| `E` | 적 |
| `!` | 위험 타일 |
| `#` | 벽 |
| `.` | 빈 타일 |

## 4. 전투 기본 규칙

### 4.1 행동과 턴

- 기본 규칙은 `1행동 = 1턴`이다.
- 플레이어는 자신의 턴에 행동 하나를 선택한다.
- 플레이어 행동이 종료되면 적 페이즈가 시작된다.
- 적은 `turnOrder` 오름차순으로 각각 행동 하나를 처리한다.
- 모든 적의 행동이 끝나면 다음 플레이어 턴을 시작한다.
- Tempo 보너스 행동과 턴 부채 행동은 기본 규칙의 예외다.

### 4.2 전체 턴 진행 순서

1. 플레이어 턴을 시작한다.
2. 현재 HP, 자세, Tempo, 체간, 턴 부채를 표시한다.
3. 공격 예고 대상과 위험 타일을 표시한다.
4. 플레이어가 행동을 선택한다.
5. 행동 가능 여부와 비용을 검증한다.
6. 플레이어 행동을 처리한다.
7. Tempo 또는 턴 부채를 사용하는 추가 행동 여부를 확인한다.
8. 추가 행동을 사용하면 플레이어 행동 단계로 돌아간다.
9. 플레이어 행동이 끝나면 적 페이즈를 시작한다.
10. 적들이 `turnOrder` 순서로 행동한다.
11. 피해, 체간, Tempo, 예고, 부채, 사망 상태를 갱신한다.
12. 승패를 확인한다.
13. 전투가 끝나지 않았다면 다음 플레이어 턴을 시작한다.

### 4.3 플레이어 기본 행동

| 행동 | 처리 |
| --- | --- |
| 이동 | 인접한 빈 타일로 1칸 이동한다. |
| 공격 | 대상에게 HP 피해와 체간 피해를 준다. |
| 방어 | 받는 HP 피해를 줄인다. 공격을 막을 때 체간이 증가한다. |
| 회피 | 위험 타일 밖으로 이동한다. 성공 조건을 만족하면 Tempo를 얻는다. |
| 대기 | 행동을 넘기고 체간을 일부 회복한다. |
| 자세 전환 | 현재 자세를 공격, 방어, 기동 중 하나로 변경한다. |
| 부채 행동 | 턴 부채를 1 증가시키고 추가 행동을 사용한다. |

- 모든 기본 행동은 행동 1회를 소모한다.
- 자세 전환도 MVP에서는 행동 1회를 소모한다.

## 5. 체간 시스템

### 5.1 공통 규칙

- 체간은 HP와 별도로 관리한다.
- HP는 사망 위험을 나타낸다.
- 체간은 행동 상실 위험을 나타낸다.
- 공격은 HP 피해와 체간 피해를 각각 가질 수 있다.
- 방어는 HP 피해를 줄이는 대신 체간을 증가시킨다.
- 체간이 최대치에 도달하면 경직 상태가 된다.
- 경직 상태의 유닛은 다음 행동 1회를 건너뛴다.

### 5.2 플레이어 체간

- 전투 시작 체간은 `0`이다.
- 기본 최대 체간은 `100`이다.
- 경직 처리 후 체간은 `40`으로 조정한다.
- 회피 성공, 대기, 방어 자세, 특정 카드로 체간을 감소시킬 수 있다.
- 방어만 반복하면 체간이 누적되어 경직될 수 있다.

### 5.3 적 체간

- 플레이어 공격에 피격되면 공격의 체간 피해만큼 증가한다.
- 공격 예고를 준비하는 중에도 체간 피해를 동일하게 받는다.
- 체간이 최대치에 도달하면 준비 중인 공격 예고를 취소한다.
- 경직 상태를 등록하고 다음 적 행동 1회를 건너뛴다.
- 경직 처리 후 체간은 최대 체간의 `40%`로 조정한다.
- 적이 대기하면 체간을 일부 회복할 수 있다.
- 적의 자세와 종류에 따라 최대 체간과 회복량을 변경할 수 있다.

적 체간 최대 도달 시 처리 순서는 다음과 같다.

```text
체간 최대 도달
-> 경직 등록
-> 준비 중인 공격 예고 취소
-> 다음 행동 1회 건너뛰기
-> 체간을 최대치의 40%로 조정
```

## 6. Tempo 시스템

### 6.1 플레이어 Tempo

플레이어 Tempo는 공격적인 대응에 성공했을 때 얻는 선택 자원이다.

획득 조건:

- 공격 예고 회피 성공
- 공격 끊기 성공
- 적 처치
- 적 체간 파괴

사용처:

- 보너스 행동
- 빠른 회피
- 강한 공격
- 턴 부채 상환

기본값:

| 항목 | 값 |
| --- | ---: |
| 시작 Tempo | 0 |
| 최대 Tempo | 5 |
| 보너스 행동 비용 | 2 |
| 턴 부채 1 상환 비용 | 2 |

### 6.2 적 Tempo

적 Tempo는 다음 강공격 시점을 플레이어에게 보여주는 위험 예고 자원이다.

획득 조건:

- 일반 공격 명중 시 `+1`
- 적 종류별 조건 달성 시 `+1`
- 패턴 성공 시 적 데이터에 정의된 수치만큼 획득

사용 규칙:

- 강공격을 예고할 때 비용을 소모한다.
- Tempo가 부족하면 강공격을 선택할 수 없다.
- Tempo는 공격 예고를 생성할 때 소모한다.
- 예고가 취소되어도 사용한 Tempo는 돌려주지 않는다.
- 경직되면 적 Tempo를 `0`으로 초기화한다.
- 현재 적 Tempo를 UI에 항상 표시한다.

기본값:

| 항목 | 값 |
| --- | ---: |
| 시작 Tempo | 0 |
| 최대 Tempo | 3 |
| 강공격 비용 | 2 |

## 7. 턴 부채 시스템

### 7.1 정의

- 플레이어가 미래 행동을 앞당겨 현재 턴에 추가 행동을 사용하는 시스템이다.
- 부채 행동을 1회 사용하면 턴 부채가 `1` 증가한다.
- 기본 최대 턴 부채는 `2`다.
- 최대치를 초과하는 부채 행동은 사용할 수 없다.

### 7.2 상환

- 다음 플레이어 턴부터 턴 부채를 상환한다.
- 턴 부채 1당 행동 1회를 잃어 상환할 수 있다.
- 턴 부채 1당 Tempo 2를 소모해 상환할 수 있다.
- 상환하지 않은 부채는 계속 유지된다.

### 7.3 유지 패널티

| 유지 중인 부채 | 체간 증가량 |
| ---: | ---: |
| 1 | +25 |
| 2 | +45 |

- 부채를 상환하지 못하면 경직 위험이 증가한다.
- 턴 부채는 짧은 순간에 높은 행동량을 제공하지만 장기전에서는 불리해야 한다.

## 8. 공격 예고 시스템

### 8.1 공격 분류

#### 일반 공격

- 예고 없이 즉시 발동한다.
- 인접한 대상에게 사용하는 근접 공격만 일반 공격으로 사용한다.
- 강공격보다 HP 피해와 체간 피해가 낮다.
- 적 행동 1회를 소모한다.

#### 강공격

- 공격 방향과 범위를 먼저 예고한다.
- 예고한 적의 다음 행동에서 발동한다.
- 일반 공격보다 HP 피해와 체간 피해가 높다.
- 예고 1회와 발동 1회로 총 2번의 적 행동을 사용한다.

#### 원거리 및 범위 공격

- MVP의 모든 원거리 공격은 예고 후 발동한다.
- 모든 범위 공격은 예고 후 발동한다.
- 예고 시 저장한 타일을 기준으로 판정한다.
- 발동 시 플레이어의 현재 위치를 다시 추적하지 않는다.

### 8.2 예고 공격 처리 순서

```text
공격 선택
-> 공격 범위 계산
-> 예고 생성 및 Tempo 소모
-> 플레이어 턴 진행
-> 적의 다음 행동에서 발동 조건 검사
-> 저장된 타일에 공격 판정
-> 예고 제거
```

예고 데이터에는 다음 정보를 저장한다.

- 공격자 ID
- 공격 ID
- 대상 타일 목록
- HP 피해
- 체간 피해
- 발동 예정 턴 또는 행동 시점

### 8.3 예고 취소

다음 조건 중 하나를 만족하면 예고를 취소한다.

- 공격자가 사망한다.
- 공격자가 경직된다.
- 플레이어가 끊기에 성공한다.

- 취소된 예고는 공격 판정을 발생시키지 않는다.
- 예고 생성에 사용한 적 Tempo는 환급하지 않는다.

### 8.4 플레이어 대응

| 대응 | 처리 | 보상 또는 위험 |
| --- | --- | --- |
| 회피 | 위험 타일 밖으로 이동한다. | 성공 시 Tempo를 얻는다. |
| 방어 | 위험 타일에 남아 공격을 막는다. | HP 피해는 감소하지만 체간이 증가한다. |
| 끊기 | 예고 중인 적을 공격해 체간을 파괴한다. | 성공 시 예고를 취소하고 Tempo를 얻는다. |

## 9. 자세 시스템

### 9.1 공통 규칙

- 자세는 유닛의 현재 전투 방식이다.
- 같은 행동도 자세에 따라 효과, 수치, 보상이 달라진다.
- 자세는 공격, 방어, 기동 3종을 사용한다.
- 플레이어의 현재 자세를 UI에 항상 표시한다.
- MVP에서 플레이어 자세 전환은 행동 1회를 소모한다.
- 이후 카드, 조건, 보상으로 무료 또는 자동 전환을 확장할 수 있다.

### 9.2 공격 자세

역할:

- 적을 빠르게 제거한다.
- 예고 공격을 끊는다.
- 적 체간을 빠르게 파괴한다.

효과 예시:

- 공격 피해 증가
- 체간 피해 증가
- 적 처치 시 Tempo 획득

단점:

- 방어 효율이 낮다.
- 자신의 체간 관리 능력이 낮다.
- 위험 타일에 남는 상황에 불리하다.

### 9.3 방어 자세

역할:

- 공격을 받아낸다.
- 체간을 관리한다.
- 방어 성공을 반격으로 연결한다.

효과 예시:

- 방어 시 받는 HP 피해 감소량 증가
- 방어 시 체간 증가량 감소
- 방어 성공 후 반격 조건 획득

단점:

- Tempo 획득 속도가 느리다.
- 적 처치 속도가 낮다.
- 전투가 길어질 수 있다.

### 9.4 기동 자세

역할:

- 위험 타일을 피한다.
- 안전한 위치를 선점한다.
- Tempo를 빠르게 획득한다.

효과 예시:

- 회피 성공 시 추가 Tempo 획득
- 이동 후 공격 강화
- 위험 타일 회피 보너스

단점:

- 정면 화력이 낮다.
- 적 체간 파괴 능력이 낮다.
- 이동 공간이 적은 맵에서 불리하다.

### 9.5 플레이어 자세 전투 예시

#### 공격 자세

- 상황: 원거리 적이 공격을 예고하고 근접 적도 남아 있다.
- 선택: 공격 자세에서 턴 부채를 사용해 추가 공격한다.
- 결과: 원거리 적의 체간을 파괴해 예고를 취소하고 부채 1을 얻는다.

#### 방어 자세

- 상황: 위험 타일 안에 있고 이동 공간이 부족하다.
- 선택: 방어 자세로 공격을 막는다.
- 결과: HP 피해와 체간 부담을 줄이고 다음 턴의 반격 조건을 얻는다.

#### 기동 자세

- 상황: 넓은 범위에 공격이 예고되어 기본 이동만으로 벗어날 수 없다.
- 선택: 기동 자세로 회피한 뒤 턴 부채로 한 칸 더 이동한다.
- 결과: 위험 범위를 벗어나 Tempo를 얻고 다음 턴에 부채를 상환한다.

## 10. 적 시스템

### 10.1 공통 규칙

- 적은 플레이어 행동이 종료된 뒤 행동한다.
- 적도 HP, 체간, Tempo를 사용한다.
- 적 종류마다 자세 하나가 고정된다.
- 적은 전투 중 자세를 전환하지 않는다.
- 적 자세는 UI에 항상 표시한다.
- 플레이어와 일부 규칙을 공유하지만 적의 행동 구조는 단순하게 유지한다.

### 10.2 적 턴 진행 순서

1. 플레이어 행동을 종료한다.
2. 적 페이즈를 시작하고 현재 전투 상태를 고정한다.
3. `turnOrder` 오름차순으로 적 행동 순서를 확정한다.
4. 현재 적의 사망, 경직, 예고 상태를 확인한다.
5. 현재 적이 행동 하나를 선택한다.
6. 즉시 행동을 처리하거나 공격 예고를 생성한다.
7. 피해, 체간, Tempo, 사망 상태를 갱신한다.
8. 다음 적을 처리한다.
9. 모든 적 처리가 끝나면 다음 플레이어 턴을 시작한다.

- 적 하나는 자신의 순서에서 행동 하나만 처리한다.
- 적 페이즈 도중 사망한 적은 이후 순서에서 행동하지 않는다.

### 10.3 적 행동 우선순위

적은 아래 조건을 위에서부터 확인하고 처음 만족한 행동 하나만 실행한다.

1. 사망 상태면 행동하지 않는다.
2. 경직 상태면 행동 1회를 건너뛴다.
3. 발동 대기 중인 예고 공격이 있으면 발동한다.
4. 일반 공격 범위 안에 플레이어가 있으면 일반 공격한다.
5. Tempo와 거리 조건을 만족하면 강공격을 예고한다.
6. 공격할 수 없으면 공격 가능한 위치로 이동한다.
7. 적 역할에 정의된 이동 조건을 적용한다.
8. 실행할 행동이 없으면 대기한다.

### 10.4 적 고정 자세

- 고정 자세는 행동 우선순위를 결정한다.
- 고정 자세는 HP, 최대 체간, 이동 능력 등의 수치 보정을 결정한다.
- 고정 자세는 공격 패턴과 약점을 결정한다.
- 플레이어는 자세를 전환할 수 있지만 적은 고정 자세로 역할을 표시한다.

#### 공격 자세 적

- 역할: 접근과 공격 압박
- 행동 우선순위: 공격 > 이동 > 대기
- 강점: HP 피해와 체간 피해가 높다.
- 약점: 최대 체간과 방어 능력이 낮다.

#### 방어 자세 적

- 역할: 이동 경로 차단과 버티기
- 행동 우선순위: 방어 > 견제 > 이동
- 강점: 최대 체간과 경직 저항이 높다.
- 약점: 이동 능력과 Tempo 획득 능력이 낮다.

#### 기동 자세 적

- 역할: 거리 조정과 측면 압박
- 행동 우선순위: 회피 이동 > 공격
- 강점: 이동 범위가 넓고 위치 선점에 유리하다.
- 약점: HP와 최대 체간이 낮다.

### 10.5 기본 적 유형

| 유형 | 고정 자세 | 일반 공격 | 강공격 |
| --- | --- | --- | --- |
| 근접 공격형 | 공격 | 인접 즉시 공격 | 전방 내려찍기 예고 |
| 원거리 공격형 | 기동 | 없음 | 직선 사격 예고 |
| 방어형 | 방어 | 인접 밀치기 | 전방 범위 밀치기 예고 |
| 기동형 | 기동 | 인접 빠른 공격 | 돌진 경로 예고 |

- 적 유형은 고정 자세, 이동 규칙, 일반 공격, 예고 공격의 조합으로 만든다.

## 11. 빌드와 성장

### 11.1 성장 요소

| 요소 | 역할 |
| --- | --- |
| 카드 | 행동을 제공한다. 자세, 부채, Tempo, 체간 태그를 가진다. |
| 스탯 | HP, 체간, Tempo, 부채 한도, 자세 보너스를 조정한다. |
| 패시브 | 특정 자세 유지, 자세 전환, 부채 상환에 보너스를 준다. |
| 유물 | 기존 규칙의 조건이나 보상을 변경한다. |

### 11.2 카드 태그

| 태그 | 연결 시스템 |
| --- | --- |
| `Attack` | 공격 피해, 체간 피해, 처치 보상 |
| `Guard` | 방어, 피해 감소, 체간 관리 |
| `Move` | 이동, 회피, 위치 조정 |
| `Stance` | 자세 전환, 자세 보너스 |
| `Debt` | 부채 행동, 부채 상환, 부채 패널티 |
| `Tempo` | Tempo 획득, 사용, 최대치 |
| `Posture` | 체간 피해, 체간 회복, 경직 |

### 11.3 기본 빌드

#### 공격 빌드

- 중심: 공격 자세, 체간 파괴, Tempo 수급
- 강화: 공격 피해 증가, 체간 피해 증가, 처치 시 추가 행동

#### 방어 빌드

- 중심: 방어 자세, 체간 관리, 반격
- 강화: 최대 체간 증가, 방어 효율 증가, 방어 후 반격

#### 기동 빌드

- 중심: 기동 자세, 회피, Tempo 수급
- 강화: 회피 보상 증가, 이동 후 공격 강화

#### 부채 빌드

- 중심: 턴 부채를 사용한 한 턴의 높은 행동량
- 강화: 부채 최대치 증가, 상환 비용 감소
- 위험: 상환 실패 시 체간 누적과 행동 손실이 크다.

### 11.4 확장 스탯

| 스탯 | 효과 |
| --- | --- |
| HP | 생존력을 증가시킨다. |
| 최대 체간 | 경직까지 버틸 수 있는 한도를 증가시킨다. |
| 체간 회복 | 대기, 회피, 방어 자세의 체간 회복량을 증가시킨다. |
| Tempo 최대치 | 저장 가능한 Tempo를 증가시킨다. |
| Tempo 획득 | 조건 달성 시 얻는 Tempo를 증가시킨다. |
| 부채 한도 | 최대 턴 부채를 증가시킨다. |
| 자세 보너스 | 특정 자세의 핵심 효과를 강화한다. |

## 17. 필수 테스트

### 17.1 공통 전투

- [ ] 플레이어의 일반 행동 1회가 행동 1회를 정확히 소모한다.
- [ ] 플레이어 행동 종료 후 적 페이즈가 시작된다.
- [ ] 적은 `turnOrder` 오름차순으로 행동한다.
- [ ] 적 하나는 자신의 순서에서 행동 하나만 처리한다.
- [ ] 모든 적 행동이 끝난 후 다음 플레이어 턴이 시작된다.
- [ ] 사망한 유닛은 이후 행동하지 않는다.

### 17.2 공격 예고

- [ ] 근접 일반 공격은 예고 없이 즉시 발동한다.
- [ ] 원거리 공격과 강공격은 예고 후 다음 적 행동에서 발동한다.
- [ ] 예고 공격은 예고할 때 저장한 타일에 발동한다.
- [ ] 플레이어가 이동해도 예고 공격은 플레이어를 다시 추적하지 않는다.
- [ ] 공격자가 사망하면 예고가 취소된다.
- [ ] 공격자가 경직되면 예고가 취소된다.
- [ ] 예고 취소 시 사용한 적 Tempo가 환급되지 않는다.

### 17.3 체간과 Tempo

- [ ] 체간이 최대치에 도달하면 경직이 등록된다.
- [ ] 경직된 플레이어와 적은 다음 행동 1회를 건너뛴다.
- [ ] 적이 경직되면 적 Tempo가 0이 된다.
- [ ] 회피 성공 시 플레이어 Tempo를 얻는다.
- [ ] 공격 끊기 성공 시 플레이어 Tempo를 얻는다.
- [ ] 적 강공격 예고 시 적 Tempo가 정확히 소모된다.
- [ ] 적 Tempo가 부족하면 강공격을 선택하지 않는다.

### 17.4 자세

- [ ] 공격 자세에서 공격 보너스가 적용된다.
- [ ] 방어 자세에서 방어 시 체간 증가량이 감소한다.
- [ ] 기동 자세에서 회피 보너스가 적용된다.
- [ ] 적의 고정 자세가 능력치에 적용된다.
- [ ] 적의 고정 자세가 행동 우선순위에 적용된다.
- [ ] 적은 전투 중 자세를 전환하지 않는다.

### 17.5 턴 부채

- [ ] 부채 행동 사용 시 턴 부채가 1 증가한다.
- [ ] 턴 부채 상환 시 행동 1회 또는 Tempo 2를 소모한다.
- [ ] 상환하지 않은 부채에 따라 체간 패널티가 적용된다.
- [ ] 최대 부채를 초과하는 추가 행동은 차단된다.

## 18. 미결정 사항

다음 항목은 기본 전투 플레이 테스트 후 확정한다.

### 18.1 자세 전환 비용

- MVP: 행동 1회를 소모한다.
- 검토안: 특정 카드 사용 시 무료로 전환한다.
- 검토안: 카드 태그에 따라 자동 전환한다.

### 18.2 턴 부채 상환 방식

- 현재안: 행동 손실 또는 Tempo 2 소모 중 하나를 선택한다.
- 검토 항목: 상환 시점과 선택 순서
- 검토 항목: 체간 유지 패널티 적용 시점

### 18.3 덱빌딩 범위

- 덱의 기본 카드 수
- 카드 보상 빈도
- 자세 태그별 카드 비율
- 카드 드로우 및 손패 규칙
- 카드 소모, 재사용, 덱 순환 방식

### 18.4 우선 검증 순서

1. 기본 전투가 정상적으로 진행되는지 검증한다.
2. 세 자세의 플레이 방식이 실제로 구분되는지 검증한다.
3. 턴 부채의 보상과 위험이 모두 체감되는지 검증한다.
4. 적 Tempo로 강공격 시점을 예측할 수 있는지 검증한다.
5. 적 고정 자세만 보고 역할과 약점을 구분할 수 있는지 검증한다.
6. 검증 후 전투 보상과 덱빌딩을 확장한다.
